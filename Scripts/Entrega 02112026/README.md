En este directorio te vas a encontrar 3 scripts diferentes y la guía de uso, como justificación matemática de uno de ellos.



Todos los scripts se deberán ejecutar, en una terminal, desde esta misma carpeta y deberá estar guardada en un lugar al que tenga acceso Python y se deberá tener instalada una versión superior a la 3.0.



Los ficheros que se encontrarán son los siguientes :





* **prop\_submarina\_v1.py** : es un script que hace el cálculo de la potencia óptica perdida tras propagarse una distancia L. Utiliza la ley de Beer-Lambert para ello. Se pueden añadir ángulos de incidencia y considera que parte de una interfaz aire-PMMA-agua.



* **schnell\_refraction\_v1.py** : es un pequeño script que implementa mediante UI un cálculo y representación dinámica de un rayo incidiendo desde un medio, N1, en otro, N2. 



* **raytracing\_submarino\_v1.py** : simulador que utiliza la propagación y seguimiento de rayos para simular el comportamiento de un haz láser fotón a fotón. 



* **raytracing\_sim\_v1.pdf** : documento que justifica la implementación del simulador por *raytracing* y sirve a la vez como guía de uso del mismo.
